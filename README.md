# متجر Easy Shop

تطبيق Flutter للتسجيل والدخول، التحقق عبر OTP، واستعراض المتجر. يستخدم
الخادم `https://easylearn.devawy.com/api` افتراضياً.

## تشغيل التطبيق

مرّر مفتاح `x-api-key` عند التشغيل، من دون حفظه داخل ملفات المصدر:

```powershell
flutter run --dart-define=API_KEY=<your-api-key>
```

يمكن تغيير عنوان الخادم عند الحاجة باستخدام
`--dart-define=API_BASE_URL=https://example.com/api/`.

التسجيل يرسل بيانات الحساب والحقول الاختيارية كـ `multipart/form-data`. بعد
إنشاء الحساب يطلب التطبيق رمز OTP عبر تسجيل الدخول؛ وبعد التحقق من الرمز يحفظ
رمز الجلسة ويرسل ترويسة `Authorization: Bearer ...` لطلبات المتجر. يمكن طلب
إعادة إرسال الرمز من شاشة التحقق. لا يعتمد التطبيق على ETag أو على واجهة
تجديد/تسجيل خروج غير متوفرة ضمن عقد الـAPI الحالي.
