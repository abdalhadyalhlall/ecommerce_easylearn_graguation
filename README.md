# متجر Easy Shop

تطبيق Flutter للتسجيل والدخول، التحقق عبر OTP، واستعراض المتجر.

## إعدادات التشغيل

إعدادات الـAPI محفوظة في ملف `.env` بجذر المشروع. هذا الملف مستثنى من Git؛
عند استنساخ المشروع، أنشئ الملف محلياً بهذا التنسيق:

```dotenv
API_BASE_URL=https://easylearn.devawy.com/api
API_KEY=your-api-key
```

بعدها شغّل التطبيق باستخدام `flutter run`. يتم تضمين `.env` في حزمة التطبيق
ليتمكن Flutter من قراءته، لذلك لا تضع فيه أسراراً لا يجوز أن تكون متاحة
لمستخدمي التطبيق.

التسجيل يرسل بيانات الحساب والحقول الاختيارية كـ `multipart/form-data`. بعد
إنشاء الحساب يطلب التطبيق رمز OTP عبر تسجيل الدخول؛ وبعد التحقق من الرمز يحفظ
رمز الجلسة ويرسل ترويسة `Authorization: Bearer ...` لطلبات المتجر. يمكن طلب
إعادة إرسال الرمز من شاشة التحقق.
